# Cadence

Музыкальный плеер для iPhone: привычный интерфейс в духе Apple Music (по умолчанию) или строгий Rockbox/iPod с Cover Flow (тема Classic). Разрабатывается с Windows, без мака: IPA собирается в облаке (GitHub Actions).

## Что есть (v0.4)

- **Библиотека с базой**: теги и обложки читаются один раз и сохраняются (`library.json`), при запуске папка не сканируется. Новые файлы подхватываются кнопкой **Settings → Update Library** (читает только новое и изменённое) или pull-to-refresh на Albums/Songs. Там же **Rebuild from Scratch**, если нужно перечитать всё.
- **Теги FLAC и обложки FLAC** читаются собственным разбором (AVFoundation на iOS их не видит, из-за этого раньше почти всё падало в Unknown Album). MP3, M4A, WAV, AIFF через AVFoundation. Если встроенной обложки нет, ищется `cover.jpg` / `folder.png` рядом.
- **Альбомы без тега**: песня в папке альбома берёт имя папки; если лежит прямо в корне, правило выбирается в Settings (по названию песни, «Артист · Singles» или один Unknown Album). Имя файла разбирается: `01 - Название`, `Артист - Название`.
- **Ручная правка**: долгое нажатие на песню или альбом → Edit (название, исполнитель, альбом, исполнитель альбома, номер, диск, год). **Settings → Fix Albums** показывает песни без альбома, можно выбрать пачку и назначить им альбом разом. Файлы не меняются, правки лежат в `edits.json` и переживают пересканирование.
- **Привычный интерфейс**: сетка альбомов, список песен с буквами и поиском, страница альбома, мини-плеер над вкладками, большой плеер с подсветкой под обложку, очередь, свайпы песен (play next / в очередь).
- **Жесты и анимации**: свайп вниз закрывает плеер, свайп по обложке листает треки, мини-плеер: свайп вверх открывает, влево/вправо листает, свайп от левого края возвращает со страницы альбома, обложка «дышит» при паузе, хаптики.
- **Редактор темы внутри приложения** (Settings → Edit Theme): цвета, фон, стекло, скругления, шрифт, параметры Cover Flow. Окно выезжает наполовину, приложение выше меняется вживую. Можно описать вид словами и получить тему от ИИ-сервера, либо нажать Random Palette.
- Cover Flow, Now Playing в альбомной, фоновое воспроизведение, управление с экрана блокировки, WAVE и ИИ (см. ниже).

Пока нет: OGG/Opus/APE (нужен libVLC), видео, плейлисты, эквалайзер, импорт кнопкой внутри приложения.

## Как собрать и поставить

1. Создай репозиторий на GitHub и запушь туда эту папку (ветка `main`).
   - Публичный репо = бесплатные минуты Actions. В приватном macOS-минуты считаются с большим множителем, так что бесплатного лимита хватит ненадолго.
2. Открой вкладку **Actions → Build IPA**. Сборка стартует сама на каждый пуш, либо кнопкой **Run workflow**. Занимает несколько минут.
3. Когда зелёная, скачай артефакт **Cadence-ipa** (внутри `Cadence.ipa`).
4. Поставь через **Sideloadly** на iPhone (бесплатный Apple ID: подпись живёт 7 дней, потом переустановка поверх, музыка не пропадёт).
5. На iPhone: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID. Включить режим разработчика, если попросит.

## Как закинуть музыку

После первого запуска в приложении Файлы появится **На iPhone → Cadence**. Туда копируй папки с альбомами:

- прямо с телефона через Файлы (из iCloud, с флешки и т.д.)
- с Windows через приложение **Устройства Apple** (или iTunes) → iPhone → Общие файлы → Cadence

Структура любая, лучше `Артист/Альбом/01 - Трек.flac`. Вернись в приложение и нажми **Settings (шестерёнка) → Update Library**: читаются только новые файлы. При первом запуске после установки библиотека читается один раз сама (на тысячах FLAC с большими обложками это может занять минуту-другую, идёт прогресс).

## Темы

Тему можно собрать прямо в приложении (**Settings → Edit Theme**) или нарисовать в дизайн-стенде (HTML-страница, там же ИИ-дизайнер) и перенести как JSON. В редакторе есть **Copy JSON** и **Paste JSON**, формат один и тот же.

Новое поле `ui`: `"modern"` (привычный вид, SF-шрифт) или `"classic"` (Rockbox). Шрифты теперь: `sf`, `rounded`, `serif` (системные) и прежние `sys`/`jb`/`plex`/`space` (моноширинные). Встроенные: Music (по умолчанию), Music Light, Cover Glow, Night Blue, а также Rockbox, Sea Glass, Paper Light, Cover Glow Classic.

Ещё способы поставить тему:

1. В стенде нажми **Copy JSON**, на iPhone открой **THEME → ВСТАВИТЬ ТЕМУ ИЗ БУФЕРА**.
2. Положи файл `theme.json` в **Файлы → На iPhone → Cadence**. Он применяется сам при следующем открытии приложения.
3. Положи несколько файлов в папку `Themes` там же, выбирай их в **THEME**.

Любое поле в JSON можно не указывать, подставится стиль Rockbox. Код: `ThemeSpec.swift` (поля и разбор), `ThemeStore.swift` (хранение), `Views/ThemeViews.swift` (фон, стекло, экран выбора).

Что пока отличается от превью: шрифты JetBrains/Plex/Space Mono не вшиты, везде системный моноширинный; размытие стекла в приложении берётся из системного материала, ползунок `gBlur` на него не влияет; настоящее iOS 26 Liquid Glass можно подключить отдельным шагом.

## Моя волна и ИИ (вкладка WAVE)

Приложение запоминает, что ты слушаешь (трек засчитывается после минуты или половины), что скипаешь и что лайкаешь (сердце в Now Playing). Из этого строится вкус, и на нём работает всё остальное. История лежит локально в `Application Support/Cadence/taste.json`.

- **MY WAVE**: бесконечная очередь по вкусу и времени суток. Можно выбрать настроение чипами или написать текстом («грустно под дождь», «для кода», «что-нибудь новое»). Очередь пополняется сама, скипы учитываются на лету.
- **RANDOM**: случайный трек, альбом или исполнитель. ANY = чистый рандом, TASTE = с перекосом в любимое, NEW = только то, что ещё не слушал.
- **FOR YOU**: забытое (раньше крутил), ни разу не слушал, сейчас в ротации.
- **Сон-таймер** и **лайк** в Now Playing.

ИИ-сервер нужен только для трёх вещей, всё остальное работает офлайн:

1. **MOOD TAGS**: один раз размечает альбомы по настроению (по 12 штук за запрос, результат кешируется навсегда). Пока не размечено, настроение выводится из жанрового тега файла.
2. **Текст -> волна**: разбирает запрос в фильтр. Без сервера работает простой локальный разбор по ключевым словам.
3. **DISCOVER**: альбомы, которых у тебя нет, под твой вкус (MY TASTE / EXPAND / CLASSICS / FRESH). Результат можно искать в Яндекс Музыке, YouTube Music, Apple Music и копить в вишлист. ИИ может выдумать альбом, всегда проверяй через SEARCH.

Настройка в **Settings → AI Server** (или в блоке **SERVER** внизу вкладки WAVE): адрес (`http://192.168.1.50:8080`), модель (можно пусто), ключ. Подойдёт любой OpenAI-совместимый endpoint (llama.cpp server, Open WebUI, Ollama). Вне дома только через VPN/Tailscale или HTTPS с ключом.

## Если Cover Flow выглядит не так

Все параметры наклона, отступов и перекрытия лежат в теме (`angle`, `flip`, `spread`, `overlap`, `sideScale`, для альбомной `spreadL`, `overlapL`, `coverL`). Если боковые обложки наклонены в другую сторону, поставь `"flip": true`.

## Если сборка упала

Открой упавший запуск в Actions, в конце лога блок `=== ERRORS ===` покажет ошибки компилятора. Код написан без возможности скомпилировать его локально, так что первая сборка может потребовать правок. Скинь ошибки Claude Code, он починит.
